# application/dtos/

Plain data objects (Pydantic) that cross the application boundary.

| Folder | What it is |
|---|---|
| [`inbound/`](inbound/README.md) | The request and answer objects of the inbound ports (`ports/inbound/`). |
| [`outbound/`](outbound/README.md) | The domain's own classes the outbound adapters exchange with the application (`ports/outbound/`). |
