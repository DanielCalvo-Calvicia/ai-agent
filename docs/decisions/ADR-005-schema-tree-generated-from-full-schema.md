# ADR-005 — The schema tree is generated from `full.schema.json`

**Status:** Accepted (2026-10-05)

## Decision

In `schema/response/general/` and `schema/response/motion/`, `full.schema.json` is the one file edited by hand. Every other file (one per node) is generated by `scripts/split_schemas.py --write`; without the flag the script only checks. `tests/test_schema_tree.py` fails on drift. The files the phases load must keep their content (`tests/test_flow_golden.py`).

## Consequences

- Positive: one place to edit an answer's shape; no silent drift between the pieces.
- Negative: after every edit, run the script and keep prompts, schemas and `domain/` in sync (see [rules/schemas-and-prompts.md](../rules/schemas-and-prompts.md)).
