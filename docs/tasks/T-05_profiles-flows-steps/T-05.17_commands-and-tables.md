## Specification

- The fixed set of messages is in `tests/manual/profile_messages.json`: a greeting, a question, a plan, a movement, a Dynamics question and a message in Spanish, each with what a good answer must contain (T-06.2 refines it). It costs a few cents per profile; the maintainer decides when to run it.
- The cost table of a profile uses the prices of `config/*_models.json`; the generated files are not edited by hand.

## Acceptance criteria

`check_agent.py --explain special` prints the assembled agent; the generators write one table per profile; `run_profile.py` on a mock adapter writes the answers and the note (the real run is T-05.11 and T-06.6).
