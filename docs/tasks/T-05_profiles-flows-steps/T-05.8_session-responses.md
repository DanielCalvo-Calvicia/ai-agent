## Goal

The session keeps one `Response` per request instead of text pairs; a step reads the last N entries (PR-005 section 7, Q09-4).

## Files

| Action | Path |
|---|---|
| Modify | `application/service/session_service.py` (`UserSession.remember`, the history passed to the agent) |
| Modify | `application/engine/state/flow_state.py` (`history_as_dicts()` takes the input and the output of each entry from its `user_goal`) |
| Modify | `tests/**` that build a history of text pairs |

## Specification

- Each request appends the `Response` of the last step of its flow; the history a step reads is the last `history_turns` entries (`AI_AGENT_HISTORY_TURNS`, 6).
- **`history_as_dicts()` returns exactly what it returns today** for the same exchange, so the prompts and the golden file do not change: the user text and the reply, read from the `user_goal`.
- A profile that ends in a code step with no `Response` (`gesture`) adds no entry.
- The history is the session's own copy and is never taken from `inputs` (T-05.9).
- An entry is never written to a log (it holds the user's text).

## Acceptance criteria

A test that runs three messages in one session gives the same `conversation_history` as the old text pairs did; the golden file does not change.
