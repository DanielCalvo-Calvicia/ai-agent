## Specification

- The golden file: **read the diff first**, then regenerate once on purpose. Each request of a step must equal today's request of the same step; the block of `special` is today's identification request followed by today's special requests. A request that differs is a bug in the task that caused it, not an update.
- `dynamics` runs with a scripted MCP list that has only Dynamics tools; `default` with none.
- The plug-and-play test copies a profile (`chat`) to a temporary folder with another name, assembles and answers; it fails if any file of the repository had to change.

## Acceptance criteria

The suite is green; the golden diff was read and is explained in *Notes*; the plug-and-play test passes.
