## Specification

1. Set `GOOGLE_API_KEY` and `GOOGLE_URL` only in the environment; the active profile is `proven`; to try `google_free` set `profile` in a copy of `config/step_models.json` and point `AI_AGENT_MODELS_FILE` at it (its `gemini-3.6-flash` steps may hit the free-tier limit).
2. Run `tests/manual/debug_flow.py --real` (or `full_flow_real_llm.py`) with a conversation message, a task message and a movement message. Look at: the model each step used, the tokens (sent, answered, thinking), whether any step is refused by the free tier, the time of the whole message, and that the replies are correct and speakable.
3. Update `measured_runs.json` and `step_tokens`, and regenerate T-02.8.
4. Record the result and any failure in *Notes* and in `requirements.md`. A failure becomes a new task.

**The maintainer decides when the epic is done.** This run can share its real call with T-01.9.

A failed call is retried 3 times with no waiting, and the client's own retry makes one failing message take minutes.
