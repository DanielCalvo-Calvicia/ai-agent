## Specification

- `DEFAULT_MODEL = GoogleModels.GEMINI_3_1_FLASH_LITE` for triage, data engineer, answer checker, user clarification and emotion reader; `GoogleModels.GEMINI_3_8_FLASH` for the others (the table of decision 1). The constants stay at the top of each file (`test_phase_structure.py`).
- Type the model of a phase as `GoogleModels`; `model_for_phase` takes the same type.
- Remove the GitHub route from `_OPENAI_COMPATIBLE_ROUTES`, the two GitHub fields of `VercelAIConfig` and the GitHub check of `/available`.
- `GITHUB_PAT` and `GITHUB_API_KEY` are no longer read.

## Acceptance criteria

No `GithubModels`, `github_api_key`, `github_url`, `GITHUB_PAT` or `is_github` in `application/`, `infrastructure/` and `domain/`; with the config file absent, every phase gets its Google default; `GET /available` is true with only `GOOGLE_API_KEY` and `GOOGLE_URL` set.
