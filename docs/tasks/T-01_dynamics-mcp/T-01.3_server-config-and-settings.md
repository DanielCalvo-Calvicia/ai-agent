## Specification

- `mcps/dynamics_microservice.json`: `{ "dynamics_microservice": { "type": "streamable_http", "url": "${DYNAMICS_MCP_URL}" } }`. The path `/mcp` is part of the variable's value (the Go `MCP_PATH` can change).
- `expand_env` leaves an unset reference as written. A server whose `url` still contains `${` must be **skipped with a warning** that names the server and the variable, not crash a message and not be offered to the planner (it would plan calls that cannot run).
- T-01.1 chose the Go service's defaults for the environment and company (Q01-8 A): nothing about them is configured or passed here.
- The URL is a **public IP and port today, over plain HTTP (accepted for the first stage, Q02-4 A), set only in the environment** (Q02-3); never in git. It will change to a cluster service name when ai-agent moves inside Kubernetes (a documented step).
- **Model (Q01-6, Q02-8):** a profile in `config/step_models.json` that puts the same Claude Sonnet model on every step. The id is `claude-4-6-sonnet-latest` (already in `AnthropicModels`, so no row is added; Q04-4). It is confirmed in T-01.9. The profile is not made active by this task unless the maintainer says so.
- **Allowed tools (Q03-2 A).** The server file has a list, for example `"allowed_tools": ["customer_orders", "order_status", "customer_card", "get_guidance", "list_workflows", "get_job_result", "cancel_job"]`. The catalog offers only those; any other tool the server lists (for example `run_query` if the Go side is misconfigured) is hidden from the planner and logged as a **warning** with the tool name. A server file without the list offers every tool (the existing servers keep working). A new tool is a one-line change on purpose.
- Leave `mcps/aws_microservice.json` unchanged unless T-01.1 says it is the same service.

## Acceptance criteria

With `DYNAMICS_MCP_URL` set the server is in the list the application gets, with only its allowed tools (a tool outside the list is hidden and logged as a warning); without it a warning is logged and the other servers work; the shipped file holds no host.
