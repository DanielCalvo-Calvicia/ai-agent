## Questions

1. **Which tools are offered to the agent.**
   - A: only the workflows `customer_orders`, `order_status`, `customer_card` plus `get_guidance`, `list_workflows`, `get_job_result`, `cancel_job`. The Go service is started with `MCP_EXPOSE_GENERIC_TOOLS=false`. **Recommended:** a small, validated surface, and the planner cannot build free queries.
   - B: also `list_tables`, `describe_table`, `plan_query`, `run_query`.
2. **Customer and order data leaves the machine.** Every call sends it to the LLM provider of the step that reads it and, when its keys are set, Langfuse stores prompts and answers (F11).
   - A: accept it for these tools.
   - B: use a Langfuse project that is trusted for it. **Recommended** if Langfuse stays on.
   - C: leave the Langfuse keys empty for runs that use these tools.
3. **How ai-agent reaches the Go service.** Host and port (not written in git), directly or through the AWS Lambda; if through the Lambda, whether it forwards `POST /mcp`. The URL goes in `DYNAMICS_MCP_URL` (T-01.3).
4. **Environment and company.**
   - A: always the defaults of the Go service (`MCP_ENVIRONMENT`, `MCP_COMPANY`). **Recommended** for the first version.
   - B: the user can name them and the planner passes them.

## Resolution

Decided by the maintainer on 2026-10-27 in [Q01](../../setup/questionnaires/Q01_dynamics-mcp.md), [Q02](../../setup/questionnaires/Q02_after-q01.md), [Q03](../../setup/questionnaires/Q03_refinement-and-good-practices.md) and [Q04](../../setup/questionnaires/Q04_last-clarifications.md). Where an answer said "Default" it took the default written in the question.

1. **Tools: A.** Only the workflows `customer_orders`, `order_status`, `customer_card` and their helpers (`get_guidance`, `list_workflows`, `get_job_result`, `cancel_job`); the Go service is started with `MCP_EXPOSE_GENERIC_TOOLS=false` (Q01-1).
2. **Data and Langfuse: B, with a note.** A Langfuse project that is trusted for it. In the prototype phase the maintainer wants to **see the data in Langfuse**; later the data will be stored in a more secure store on AWS or SQL. **No masking in this epic** (Q01-5, Q02-6 A). Written as a known limit.
3. **Reaching the Go service.** The Go service is open today, so it is reached with a **public IP and port, configured only through an environment variable** (`DYNAMICS_MCP_URL`; never written in git). Plain HTTP over that path is accepted for the first stage (Q02-3, Q02-4 A). Later ai-agent moves **inside the Kubernetes network** (a web chat as the client); that is a documented step, not a task (Q01-7, Q02-5 A).
4. **Environment and company: A.** Always the defaults of the Go service, against the sandbox; the user cannot name them (Q01-8).
