## Goal

A Claude model receives a schema that Anthropic's structured outputs accept, and every other provider receives what it received before.

## Files

| Action | Path |
|---|---|
| Create | `infrastructure/outbound/llm/anthropic_schema.py` |
| Modify | `infrastructure/outbound/llm/vercel.py` (`_build_options`, the header comment and one import) |

## Specification

- `anthropic_response_format(response_format, depth=3)`: a copy with `strict: true` and a sanitized schema; the argument is not modified.
- `sanitize_schema(schema, depth=3)`: `additionalProperties: false` on every object; the keywords `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, `minLength`, `maxLength`, `maxItems`, `uniqueItems`, `minContains`, `maxContains` removed (a property that is *called* like one is kept); `minItems` capped at 1; every `$ref` inlined, a reference met more than `depth` times along one path dropped with the array and the property that hold it, and `required` kept consistent.
- `_build_options`: the sanitized format only when `payload.model.is_anthropic()`.

## Acceptance criteria

All 10 phase schemas end in the subset (T-03.3); the options of a non-Claude model are identical to before; no change in `domain/`, the phases, the schemas or the golden file.
