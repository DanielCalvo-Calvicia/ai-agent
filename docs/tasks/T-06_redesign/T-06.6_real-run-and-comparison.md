## Goal

Run every new or changed profile on the real models and compare with the answers of T-05 (PR-005 section 11). **It costs money: ask the maintainer before each run.**

## Specification

1. `scripts/run_profile.py <profile>` for each profile of T-06.1, on the models of the profile; the Dynamics profiles need the service running.
2. For each message of the fixed set, the maintainer ticks the expected points in `tests/output/<date>_<profile>.md`.
3. Compare with the T-05 run of the same message (T-05.11 and the runs of T-05.17): note what is better, the same or worse, the tokens and the cost.
4. Write `tested: <date>` in each profile that passed; a profile that did not pass stays `null` and the reason is in *Notes*.

## Acceptance criteria

Every profile of T-06.1 has a run and a comparison; the ones that passed are marked; the cost per message of each is in the table of `check_agent.py --explain`.

**Comparison with T-05:**
- **Tokens:** lower or equal in every profile with a reference, at the same number of calls (`chat` and `default` -7%, `movement` -2%, `special` flat). The savings are those of the appends and the shorter generic and triage prompts: about 2% per call, 7% where a prompt lost a block the profile did not use (`chat` and `default` have no tools). `special` pays for its tool list and its Sonnet planner, so the saving is lost in the variation of one run (the same message took 8 calls in both runs).
- **The T-05.11 run** of `special` (one message, "Dime el estado de los pedidos del cliente CL-1001", 8 calls, 41,513 tokens): the same message now takes 8 calls and 45,294 tokens on `special` and 8 calls and 41,300 on `dynamics`. Not lower: one run of a Sonnet planner varies by more than the saving.
- **Answers:** better where the changes aimed to be: `chat` answers a Spanish question in Spanish (0 of 24 in English after change 7, against 16 of 24), the refusal ("open the window") is `communication` on `identification` in this run, the Dynamics answer for CL-1001 (5 open and 12 archived, the three most recent, in Spanish, no markdown, no `[hidden]`) is the same on `special` and `dynamics`. The movement path (`movement_es`: two movements, `movement_ask`: asked, then one movement) is as before.
