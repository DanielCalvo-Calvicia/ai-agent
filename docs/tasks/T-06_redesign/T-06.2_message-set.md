## Goal

A small, fixed set of messages with what a good answer must contain, so a prompt or a flow is judged by the same yardstick every time (Q08-5 A).

## Files

| Action | Path |
|---|---|
| Modify | `tests/manual/profile_messages.json` (T-05.17 made the first version) |
| Create | `tests/manual/README.md` (how to run it and read the results) |

## Specification

- Each message: the profile it is run on, the text, and a list of **expected points** (what the answer must say or do; for example "answers in Spanish", "states the number of orders", "asks which arm"). Real customer data never: sandbox codes only (`CL-1001`).
- At least: a greeting (Spanish and English), a question with no tool, a plan that needs a document, a movement, a Dynamics question, a message in Spanish for each profile that answers text, a message that must make the profile ask the user a question and the answer to it (the `pause_id` path).
- The set is read by `scripts/run_profile.py`; a run saves each answer and the points a human ticked in `tests/output/<date>_<profile>.md`. The judge is the maintainer (option A of Q08-5); an automatic judge is not part of this epic.

## Acceptance criteria

The set exists, each message has expected points, and a run on the mock adapter writes the file.
