## Goal

Improve the prompts that T-06.1 lists, without breaking the answer format, with a comparison for each (Q07-4: "the prompts also need refinements").

## Files

| Action | Path |
|---|---|
| Modify | `prompts/<id>_<name>.txt` of the steps in T-06.1 |
| Create | `prompts/profiles/<profile>/<step>.txt` where only one profile differs (a file named by `prompt_replace` or `prompt_append`) |
| Modify | `docs/rules/schemas-and-prompts.md` (what the prompt of each step says and why) |

## Specification

For **each** prompt, in this order:

1. Run the fixed set on the current prompt with the models of the profile; keep the output (`before`).
2. Change **one** thing (the instruction that T-06.1 names as wrong).
3. Run the same set again (`after`); keep it.
4. Write in *Notes* what changed, the messages whose answer changed and whether the expected points are met better, the same or worse. Worse: revert.
5. The golden file changes: read the diff first and regenerate on purpose (`UPDATE_GOLDEN=1`).

A prompt that differs for one profile is a profile override (T-05.14), not a change of the generic prompt.

## Acceptance criteria

Each refined prompt has a `before` and an `after` run and a note; none breaks its schema (`test_schema_tree.py`, `assemble()`); the maintainer read each changed prompt.

## Verification

The baseline of the [tasks README](../README.md) section 3. Real runs cost money: ask before each.
