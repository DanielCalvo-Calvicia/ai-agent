## Specification

- A profile that has no `flow` lists its steps (Q06-1); a flow that is reused is a flow file.
- Every profile passes `assemble()`; the safety gate is optional like every step (Q05-12), but the profiles that reach business data keep it unless T-06.1 says otherwise in writing.
- The models of each profile come from the results of T-06.6, not from a guess: start with a model set of T-05.5 and change it with the real-run results.
- `default` has no tools; only `special` and `dynamics` have the Dynamics tools (Q09-5).
- Tokens are hashes; the plain tokens are the maintainer's and are never written.

## Acceptance criteria

Each profile assembles and answers on mocks; the golden diff was read; the plug-and-play test still passes.
