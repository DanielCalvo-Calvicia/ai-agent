## Resolution

Answered by the maintainer in [Q11](../../setup/questionnaires/Q11_fast-tool-path.md) on 2026-11-11:

1. **Names:** profile `dynamics_fast`, flow `fast` (Q11-1: default).
2. **Triage inside the flow: two profiles** (Q11-3: C, not the default of the ADR). `dynamics_fast` has no triage and requires the `identification` result as `inputs` (for a client that chains: Brain); the variant with the triage is named **`<server>_fast_triage`**, so `dynamics_fast_triage` (for a client that sends only the message: a web chat, the portal). Q11-2 took the default C: both kinds of client.
3. **Read-only check:** by the `readOnlyHint` annotation; a tool without the hint is refused; it is checked at run time (Q11-5: default).
4. **A request that needs more than one tool:** the reply says it plainly and briefly; the client picks `dynamics` (Q11-6: "if default" = A).
5. **Different steps per profile: a profile can list its own steps with no flow file** (Q11-7: B, not the default). The maintainer thought that was done: it is not. `assemble()` accepts a profile's `steps` but the runner refuses it (`needs steps as files`). New task **T-08.10**. There is no other variation than question 3 (Q11-7).
6. **Models:** Haiku on the selector and the writer, Sonnet only if the quality fails (Q11-9: default).
7. **The direct call also in `special` and `dynamics`:** yes (Q11-13: default).
8. **Branch:** `feature_fast_profile`, commits only when asked, the maintainer opens the pull request (Q11-15: default).

Also decided: the client is one thing today and uses one profile, so how the client chooses between the fast and the full profile is not needed yet; **which client was not said** (Q11-4: C). Only `dynamics_microservice` uses the module for now (Q11-8). The 20 s are the request to the fast profile, the median of 5 runs (Q11-10). Every real run is asked first (Q11-11). If 20 s is not reached: stop and ask (Q11-12). The planner's extra action is not fixed in this epic (Q11-14). The token of a new profile is shown once in chat; only its hash goes in a file (Q11-16). Whether the environments' Dynamics URL points at the new service is `UNKNOWN` (Q11-17); nothing is deployed by this epic.

ADR-019 is Accepted (2026-11-11), with two changes: two profiles, and a profile can list its own steps. T-08.3, T-08.4 and T-08.10 can start (T-08.3 after T-08.2).
