The scenarios of the epic run end to end through the flow with a scripted LLM and a fake MCP server in the shapes of each protocol, and a real answer per protocol is kept as a fixture.

## Specification

Scenarios, each for both protocols where it applies: a normal answer with no job; a job that ends on the second read; a job that never ends (budget spent, `cancel_job` called, the reply says it is still running); `scope` all with two jobs (both end: both tables; one never ends: no table, the running one cancelled, the reply says it is still running); a read that fails (`error (not_found)` or a transport error); an answer of a shape the protocol does not know (the action fails, one log line with the server name, no value); a server with `job_protocol` `none` whose answer contains the word `job_id` (nothing is followed); an injected sentence inside a job answer (no other tool is called). The tests use a clock they control.

## Acceptance criteria

All scenarios pass; none takes real time; no log line, metric or span in them holds an argument or an answer.
