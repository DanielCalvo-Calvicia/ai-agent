# prompts/profiles/<profile>/

Prompt files that only one profile uses: a `prompt_replace` or `prompt_append` of a step for that profile (PR-005 section 5). The prompts every profile shares stay in `prompts/`.

Today: `tools/draft_writer.txt`, the draft writer's rules for a tool answer (a table, an error, a query still running, a `[hidden]` cell), and `tools/project_manager.txt`, the project manager's rules for choosing a tool and filling its parameters, both appended by `special` and `dynamics` (T-06.4 changes 2 and 3); `chat` and `default` have no tools and do not carry them. Both profiles name the same file on purpose; a profile that needs other rules gets its own file. A profile uses a file here as `"overrides": {"draft_writer": {"prompt_append": {"file": "prompts/profiles/<profile>/draft_writer.txt"}}}`, or writes the text inline; `prompt_replace` takes the same two forms. `python scripts/check_agent.py` refuses a missing file, a step with no prompt and a step the profile's flow does not run.
